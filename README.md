## 🚀 Sobre mí

Soy estudiante de **Ingeniería de Sistemas** en Uniremington (Medellín) y desarrollador **Full Stack** con un pie en el **IoT**. Me gusta conectar el hardware con el software: leer sensores, mover esos datos por una API segura y mostrarlos en una app web o móvil que alguien pueda usar de verdad.

- 🌀 **Vórtice Digital:** mi marca de desarrollo, con la que construyo soluciones web para negocios reales. Allí desarrollé un **e-commerce para una tienda de productos capilares**, con catálogo, carrito y gestión de pedidos, y una **plataforma de cursos** para publicar y organizar contenido formativo.
- 🎓 **Trabajo de grado (aprobado):** **WASTECH**, sistema de monitoreo IoT para la deshidratación de residuos orgánicos domésticos. Arduino + DHT11, API REST en Spring Boot con Spring Security, JWT y BCrypt, persistencia con JPA/Hibernate sobre MySQL y panel web en Thymeleaf.
- ⚡ **ElectroSafe:** monitoreo de seguridad eléctrica con ESP32 y sensores de corriente, voltaje y temperatura (SCT-013, ACS712, DHT22), mensajería MQTT, backend en FastAPI + PostgreSQL y app móvil en React Native (Expo), con CI/CD en GitHub Actions.
- 🩸 **Laboratorio de innovación:** app de banco de sangre, desde la vigilancia tecnológica y revisión de patentes hasta el desarrollo.
- 🧾 **ERP académico (equipo Nexo):** líder del módulo de Contabilidad y Facturación, con facturación electrónica DIAN, impuestos (IVA, ICA) y reportes financieros.
- 🌱 **Aprendiendo:** arquitectura de software, seguridad en APIs, IoT a escala y desarrollo asistido con IA (Claude Code en VS Code).
- 🛡️ **También me interesa:** ciberseguridad y normativa TI (ISO 27001, COBIT 2019, Ley 1581), y trabajo en Kali Linux.
